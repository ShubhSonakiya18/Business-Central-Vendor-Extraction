# --- OCR (CPU-only) ---
# PaddleOCR + PaddlePaddle. Install CPU build only -- do NOT install
# paddlepaddle-gpu, we don't need/want CUDA wheels for this pipeline.
#
# NOTE: paddleocr==3.2.0 / paddlex==3.2.1 (the versions originally pinned
# here) are broken on import: paddlex's own __init__.py eagerly imports
# every bundled pipeline, including an unrelated doc-retrieval component
# that hard-imports `langchain.docstore` -- a module removed from modern
# LangChain -- so `import paddleocr` raises ModuleNotFoundError even though
# we never touch that feature. paddleocr==3.7.0 / paddlex==3.7.2 fixed this.
# Also: do NOT install the `[all]` extra -- it pulls in that same
# doc-retrieval/RAG dependency chain (langchain, extra vector-store/LLM
# deps) that this pipeline has no use for; the base package is enough for
# text detection + recognition.
